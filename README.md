# 孤星 · 浏览器主页

按提供的孤星原图重建界面构图：右侧使用四角透视，下方模块共享同一个投影面；恢复椭圆仪表、双色功能区、错位卡片、渐隐标题倒影、纸面网格、橙色环形图标和彩色细边。保留天文台昼夜背景，将原有游戏文字与功能替换为浏览器主页用途。

桌面版对右侧构图做了统一的轻微放大并向中央延伸，同时上移、放大左侧时钟，调整便签与底部入口的尺寸和对齐；保留中央场景和模块间隙。手机沿用原有双列布局。

## 打开

Chrome 日常使用推荐扩展版：先执行 `npm run build:extension`，再选择 `build/chrome-extension` 加载已解压扩展，即可把新标签页变成此主页，立绘动画无需本地服务器。详细安装、启动页设置和原数据迁移见 [EXTENSION.md](EXTENSION.md)。修改页面后运行 `npm run build:extension` 更新项目内的扩展目录。

直接打开 `dist/index.html`，无需安装依赖；这种方式显示静态助理立绘。播放阿米娅骨骼动画请使用下方预览服务。搜索和天气需要联网，其余核心功能及本地服务中的动态立绘可离线使用。

也可以双击 `启动预览.cmd`（需已安装 Node.js），或在项目目录运行：

```sh
npm start
```

访问 `http://127.0.0.1:4173/`。预览服务运行期间，可将此地址填入浏览器的主页或启动页设置。纯网页不会自动修改浏览器的新标签页设置；新标签页替换需要浏览器支持或相应扩展。

## 功能

阿米娅立绘的绘制上限为 60 fps，保留原动作速度；实际帧率取决于显示器刷新率与设备性能。切到后台、输入或打开弹窗时仍暂停绘制。

立绘使用与原纹理匹配的预乘透明混合，避免拼接边缘被重复压暗；昼夜保留角色原始亮度与饱和度，仅调整环境投影。

1.0.5 补上 Spine 文件之外的独立星盘、飞鸟、金色刻度、星光和银河背景。使用游戏原始图层与动画曲线，粒子和材质效果由 WebGL 适配；与角色共用背景开关、暂停行为和绘制时钟。当前人物位置、120% 大小保持不变，场景延伸到视口之外的部分按主页边界裁切。

- 搜索：Bing、Google、百度和 DuckDuckGo；输入网址直接访问；最近 5 次搜索；支持 `/` 和 Ctrl/⌘ K 聚焦搜索。
- 收藏：首页两张快捷卡片和搜索区右侧两张横幅展示前四个网站；点击「网站收藏」查看全部、按分类筛选、编辑和排序；最多 60 个网站。
- 时间：本地时钟、日期、问候语；自定义称呼、12/24 小时制和秒数。
- 专注：5、15、25、45、60 分钟；开始、暂停、继续和重置；刷新后按实际时间续接。表盘按「天想」实机视频重建黑玻璃、薄白边、分段色带和前景暗色球体，配有独立轨道转面、轨迹光点、玻璃反光及球面明暗循环；彩色弧线仍表示真实剩余时间。
- 待办：添加、完成、删除和清理已完成事项。
- 随手记：自动保存、字数提示和复制。
- 常用服务：左下角 Translate 卡片打开谷歌翻译，顶部信封打开 Gmail；遵循新标签页打开偏好。
- 自动昼夜：默认开启，按设备本地时间在 18:00 切换黑夜、06:00 恢复白天；刷新及从后台返回时同步检查。可在「个性设置 → 主题与场景」关闭；手动选择场景也会关闭自动切换，保留手动选择。
- 主页助理：阿米娅「寰宇独奏」动态立绘，默认显示原模型的花枝、琴盒、漂浮物与场景光效，使用原 Idle 待机与 Interact 互动时间线。点击立绘或「互动」播放一次动作后回到待机；旁边按钮暂停/继续。「背景」按钮或设置中的「皮肤背景与动效」可切换完整场景与独立立绘，保持角色位置和 120% 大小。设置中可隐藏立绘或停用动作。输入、弹窗、后台和系统减少动态效果会暂停动画；WebGL 不可用时显示静态立绘。资源来源及运行库许可见 `dist/assets/SOURCES.md`、`dist/vendor/SPINE-LICENSE.txt`。
- 天气：手动搜索城市，展示实际温度、天气和当日最高/最低温；支持刷新与失败重试。
- 个性化：完整昼夜主题、动效开关、新标签页打开偏好。夜版对照官方动态演示重绘乳白金属图标、深色卡片、珍珠色光晕、橙红收藏与管理栏，同时覆盖搜索、便签、天气、收藏管理和设置弹窗。图标切口扫光、印刷图案反色、管理圆盘与指针独立运动，并配合错峰环形微光；输入、打开弹窗或页面不可见时自动暂停，并尊重系统减少动态效果偏好。动效为视频观察后的代码重建，周期是本项目的近似校准值，背景仍为静态图片。
- 备份：导出 JSON；导入前校验并显示覆盖确认。
- 适配：桌面沿用参考图的卡片坐标，将显示范围扩展至 2120 × 984，完整容纳边缘卡片及投影；使用布局缩放，卡片单独透视；背景铺满视口；手机使用可滚动双列布局；支持键盘焦点、Escape 关闭弹窗和减少动态效果偏好。

收藏、便签、待办、偏好及计时状态保存在当前浏览器的 `localStorage`，键为 `lone-star-home-v1`，不会跨设备自动同步。更换浏览器、访问地址或清除网站数据会影响本地记录，迁移前可导出备份。天气城市默认未设置，不申请设备定位权限。

天气使用 [Open-Meteo 天气接口](https://open-meteo.com/en/docs) 和 [城市搜索接口](https://open-meteo.com/en/docs/geocoding-api)，联网时向该服务发送所选城市相关参数。搜索按所选搜索引擎跳转。

## 文件

- `dist/index.html`、`dist/styles.css`、`dist/app.js`：新版主页。
- `dist/materials.css`：纸面纹理、卡片侧边、统一光照与分层阴影、标题倒影与叠字、中文印刷细节和仪表材质。
- `dist/motion.css`：独立的循环动效、暂停规则与减少动态效果适配。
- `dist/night.css`：整套夜间组件、弹窗、虹彩光晕与昼夜过渡；与白天版共用布局和功能。
- `dist/optics.css`：昼夜图标和面板边框的柔光散射、渐散阴影与小屏强度校准；文字和输入内容保持清晰。
- `dist/assistant.js`、`dist/assistant.css`：阿米娅立绘渲染、固定视野、互动控制与桌面/手机构图。
- `dist/assistant-scene.js`、`dist/assets/amiya/scene/`：独立星盘背景、飞鸟曲线与粒子渲染；原资源提取脚本在 `scripts/export-amiya-scene.py`。
- `dist/original.html`、`dist/original.css`、`dist/original.js`：保留的上一版游戏界面交互演示，可从使用指南进入。
- `dist/assets/`：参考图、场景素材与纹理；白天背景使用 BWIKI 收录的「星迹」1820 × 1024 PNG 原文件，夜景使用用户提供的版本；来源记录在 `dist/assets/SOURCES.md`。
- `server.mjs`：无依赖本地预览服务。
- `SECURITY_REVIEW.md`：发布前检查范围和清理说明。

使用原生 HTML、CSS、JavaScript，无构建工具、在线字体或第三方前端依赖。字体采用系统字体，图标为 SVG 重绘。
